# ClearHealth NG

A beginner-friendly health information platform that provides clear, simple health education in **English & Pidgin** for everyone in Nigeria.

> Your Health In Language You Understand

## Overview
ClearHealth NG was built to solve the problem of complex medical jargon. It explains common sickness, hospital rights, and first aid steps in simple language that anyone can understand.

The project demonstrates how JavaScript can be used for language toggling, live search, and dynamic content filtering without reloading the page.
I built this project as part of my frontend development learning journey.

## Features
- **Bilingual Support:** Toggle between English and Pidgin instantly
- **Live Search:** Search for symptoms, rights, first aid without page reload
- **Browse by Category:**
    - Common Sickness (Malaria, Typhoid, Cold)
    - Your Hospital Rights
    - First Aid
- **Featured Health Tips:** Curated wellness tips
- **Responsive Design:** Works on mobile and desktop
- **Interactive UI:** Hover effects and dynamic filtering

## Technologies Used
- **HTML:** Structure and semantic sections
- **CSS3:** Green health theme, grid layout, responsive design
- **JavaScript:** DOM manipulation, event handling, form validation, array filtering
